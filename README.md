# Malaria Incidence Analysis (2000–2024)

## Research Overview
This project examines malaria incidence trends across 97 countries from 2000 to 2024 using World Bank data.

The analysis explores:
- Changes in malaria incidence over time
- Differences across world regions
- Differences across income groups
- Country-level trends and changes
- Statistical significance of socioeconomic differences

## Research Questions
1. How has malaria incidence changed between 2000 and 2024?
2. How do malaria incidence levels and trends differ across regions?
3. Are malaria incidence levels significantly different across income groups?
4. Which countries experienced the largest decreases or increases?

## Data Source
World Bank World Development Indicators (WDI)

Indicator: Malaria incidence (per 1,000 population at risk)  
Indicator code: `SH.MLR.INCD.P3`

[View the indicator on the World Bank](https://data.worldbank.org/indicator/SH.MLR.INCD.P3)

## Methods
- Descriptive statistics
- Country-level and regional trend analysis
- Linear regression
- Kruskal–Wallis test
- Pairwise Mann–Whitney U tests with Holm adjustment

## Key Findings
- The overall average malaria incidence declined during the study period.
- Malaria incidence levels and trends differed substantially across regions.
- Statistical testing identified significant differences across income groups.
- Most countries in the study experienced a decline, although some experienced increases.

## Tools
- Python
- Pandas
- Matplotlib
- SciPy
- Jupyter Notebook

## Limitations
The analysis includes 97 countries with complete data for 2000–2024. Results are descriptive and associational and should not be interpreted as evidence of causation. Country averages are not population-weighted.
